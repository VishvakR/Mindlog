# Runbooks

Step-by-step operating procedures (PLAN 19.4), written as the features they cover land, and exercised in the phase 11 chaos week.

Planned runbooks: node crash and replacement · disk full · leader flapping · slow follower · model service down · PD quorum loss · restore from backup · rolling upgrade · rotating certificates · rotating the master key · tenant data export and deletion.

Each runbook states the symptom (alert, metric, log line), how to confirm it, the fix step by step, how to verify recovery, and what to record afterwards.
