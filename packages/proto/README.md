# @mindlog/proto

Generated TypeScript for the protobuf schemas in [`proto/`](../../proto) (ADR-0004).

- **Purpose**: one schema for replicated log commands, internal RPCs and the model-sidecar API, shared by TypeScript and Python.
- **Public API**: message schemas (`CommandSchema`, `HlcSchema`, `RequestIdSchema`, `ErrorDetailSchema`) and their types. Use `create`, `toBinary` and `fromBinary` from `@bufbuild/protobuf`.
- **Invariants**:
  - `src/gen/` is generated by `pnpm proto:gen` and committed. Never edit it by hand; CI regenerates and diffs.
  - 64-bit fields are `bigint`.
  - Field numbers are never reused. `Command` body numbers 10–99 stay `reserved` until each body lands.
- **Metrics**: none.
