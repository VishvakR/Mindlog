# mindlog-proto

Python modules generated from [`proto/`](../../proto) (ADR-0004), imported as `mindlog.v1`.

- Generated by `scripts/gen-proto.sh` with `grpcio-tools`, which writes `*_pb2.py` plus `.pyi` stubs. Never edit them by hand.
- `mindlog` is a namespace package, so other distributions can add `mindlog.*` modules.
- `tests/` pins the wire bytes of a reference `Command`. The TypeScript tests in `packages/proto` pin the same bytes, so the two languages stay compatible.
